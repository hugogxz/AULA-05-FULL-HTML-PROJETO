# Resident Evil — Enciclopédia Temática

Projeto acadêmico elaborado para a disciplina de HTML, utilizando exclusivamente **HTML**, sem aplicação de CSS ou JavaScript. O site apresenta a franquia **Resident Evil** através de seus 12 principais jogos, organizados conforme o lançamento, além de conteúdos sobre spin-offs, personagens, vírus e um formulário demonstrativo.

## Como visualizar

Para acessar o projeto, abra o arquivo `html/index.html` em um navegador. Todas as páginas possuem links de navegação que permitem explorar o conteúdo da enciclopédia.

## Requisitos e recursos utilizados

* Estruturação com as tags `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
* Reprodução de arquivos locais utilizando `audio` e `video`.
* Utilização de `figure` e `figcaption` para imagens e suas descrições.
* Formulário contendo `date`, `file`, `color`, `range`, `required` e `placeholder`.
* Implementação de `datalist` para sugestões de preenchimento.
* Elementos interativos através de `details` e `summary`.
* Uso de `abbr`, `del`, `ins`, `progress` e `meter` para diferentes formas de marcação de conteúdo.
* 17 páginas HTML conectadas por meio de um sistema de navegação.
* Organização dos arquivos em diretórios específicos para HTML, imagens, áudios e vídeos.
* Desenvolvimento realizado sem CSS e JavaScript.

## Sobre o projeto

A proposta da enciclopédia é apresentar informações de forma simples e organizada, permitindo conhecer diferentes momentos da franquia Resident Evil e seus principais elementos. O projeto também serve como exercício prático dos recursos fundamentais da linguagem HTML.

## Aviso

**Resident Evil**, seus jogos, personagens, imagens e demais propriedades relacionadas pertencem aos seus respectivos detentores de direitos, incluindo a **Capcom**.

Este projeto possui finalidade exclusivamente **acadêmica e educacional**, não tendo qualquer objetivo comercial. Materiais externos presentes no site são utilizados apenas para fins ilustrativos e de estudo.
